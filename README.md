
# Vee AI Video Maker

Vee AI Video Maker is a free browser-based prototype for creating
vertical videos for TikTok, YouTube Shorts and Facebook Reels.

## Features

- Enter a video topic
- Select from four visual styles
- Choose 15-second or 30-second videos
- Generate animated scenes automatically
- Preview videos in a vertical 9:16 format
- Download recordings as WebM
- No API key or account required

## How to use

1. Open the website in a modern browser.
2. Enter your video topic.
3. Choose a visual style and video length.
4. Click Create My Video.
5. Wait for recording to finish.
6. Click Download My Video.

## Technology

- HTML
- CSS
- JavaScript
- HTML Canvas
- MediaRecorder API

## Current limitations

This is an animated-text video prototype.
It does not yet generate original AI footage, AI cartoon
characters, AI voices, or background music.

Video recording support depends on the user's browser.

## Hosting

The prototype can be hosted on GitHub Pages for testing.
For a commercial service, choose hosting that permits SaaS
and add a secure backend before connecting AI services.
