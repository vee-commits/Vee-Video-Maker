# Vee Video Maker

An easy-to-use, browser-based video maker and caption animator designed for creating short-form content for Instagram Reels, TikTok, YouTube Shorts, and LinkedIn.

## 🚀 Features
- **Kinetic Text Animator**: Automatically animates your script sentence-by-sentence.
- **Dynamic Particle Backgrounds**: Choose between Neon Floating Particles, Cyber Matrix Grid, and Deep Gradient Glow.
- **Mobile & Desktop Responsive**: Optimized to run directly in any web browser without installation or server setup.

## 🛠️ How to Use
1. Open the live site on GitHub Pages.
2. Paste your script into the text area.
3. Choose your background theme.
4. Click **▶ Play Preview** to watch your video caption preview in real time!

## 💻 Tech Stack
- HTML5 / CSS3
- JavaScript (HTML5 Canvas Engine)
